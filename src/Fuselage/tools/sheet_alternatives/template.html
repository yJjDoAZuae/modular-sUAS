Three quarters for the drawing

The view is meant to have at least {{required}} % of the frame, and the title block and the values are meant to share the rest. Here is what each layout actually leaves the view, drawn at the size it would be.

Decided 2026‑08‑22 — compact the table, and draw our own title block. Compaction takes the table from a third of the frame to a ninth, and the view still cannot reach {{required}} %: the stock title block caps it at {{ceiling}} % on its own, before a single value is printed. What the decision specifies is an envelope rather than a size — the block fits inside 143.4 × 46.8 mm, and every block inside it measures the same.

How many values is this about?

The answer to that question is what makes the rest of the page surprising. The largest table in the drawing set prints 68 numbers.

No unit is repeated, and none is printed at all. A cell is a bare number. The only text in the table that is not a number is a column heading, and on a family sheet that is one callout letter. Where a unit does appear it is inside a panel stock name used as a band heading — 3/16in, eight times across one band — and that in is the same for every column in the band.

Where each step came from. Per-column decimals — DECIMAL_PLACES is a bound on the precision a value may carry, and it was being read as an instruction to print that many places whatever the value is, so a column reading 4.00, 10.00, 5.00 spent six characters where one would do. Short band headings — the in is the same down the whole band, so it is stated once above it. The gutter — H2’s one-text-height rule is about annotations floating on a view with nothing between them; a ruled table has a rule between its columns, which is what a rule is for. This was the largest single saving and it was a rule applied where it does not apply. The row pitch — 2 h was chosen so the table’s rhythm would match the dimension lanes’, an argument about how the sheet looks made before anyone knew what the rhythm cost. Packing — there was none: blocks were stacked in one column, so a 10‑row block under a 9‑row block cost 19 rows. The two have nothing to do with each other.

The view is a rectangle, so its share is a packing result

Not the frame less two areas. A view is a projection with a bounding box, so what it gets is the largest rectangle left once the title block and the table are placed — and only two placements leave a rectangle at all.

The title block binds twice. It is {{block_area}} mm² — {{block_share}} % of the frame, and {{block_of_rest}} % of everything that is not the view, larger than every family’s table put together. Its depth caps the view at {{ceiling}} % with no table on the sheet at all. Its width leaves 91.9 mm beside it, and the compacted table is 95.1 mm, so the band placement is unavailable and the layout falls back to the column.

Which is why packing the blocks abreast lowers the view’s share: it trades nine rows it no longer needs for 25 mm of width it cannot afford. That is not an argument against packing. It is the measurement saying the table was never the thing taking the room.
